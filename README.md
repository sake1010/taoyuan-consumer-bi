# 桃園市消費諮詢商品類型分析｜互動 BI

## 專案目的
以桃園市政府「消費諮詢商品類型分析表（109–114年）」為資料基礎，分析各年度消費諮詢件數、商品類型排名、占比與跨年趨勢。

## 資料來源
- 原始檔：`data/raw/taoyuan_consumer_consultation_raw.csv`
- 原始檔名稱：桃園市政府消費諮詢商品類型分析表（109-114年）.csv
- 資料期間：民國 109–114 年（西元 2020–2025 年）
- 目前此專案根據使用者提供的 CSV 製作，尚未獨立驗證資料頁面與更新頻率。

## 專案檔案
- `data/raw/`：原始 CSV
- `etl/etl.py`：ETL 程式
- `data/processed/taoyuan_consumer_consultation_clean.csv`：轉換後長表，供網頁讀取
- `data/processed/validation_report.csv`：各年度加總驗證
- `index.html`：互動 BI 網頁

## ETL 流程
1. 讀取原始 CSV。
2. 檢查必要欄位、重複年度、缺失值與負數。
3. 將民國年轉換成西元年。
4. 將商品類型寬表轉換為長表。
5. 計算各商品類型占該年度總件數的百分比。
6. 核對商品類型加總是否等於原始「合計」；若不一致則停止輸出。

執行方式（需安裝 Python 與 pandas）：

```bash
pip install pandas
python etl/etl.py
```

## 互動功能
- 年度篩選：更新 KPI、排名與占比圖。
- 商品類型篩選：更新該類型跨年度趨勢。
- 排名數量切換：顯示前 10、前 15 或全部類型。
- KPI 與洞察文字會依選取條件動態更新。

## 發布 GitHub Pages
1. 建立新的 **Public** repository。
2. 上傳本專案全部檔案，保留資料夾結構。
3. 進入 `Settings → Pages`。
4. 選擇 `Deploy from a branch`、`main`、`/(root)`，儲存。
5. 等待發布完成，開啟 Pages 網址檢查電腦與手機版。
6. 如果修改原始資料，請重新執行 ETL，將輸出檔與程式一起提交。

## 指標與限制
- 件數：原始資料中各商品類型的諮詢件數。
- 占比：該商品類型件數 ÷ 該年度總件數 × 100%。
- 年增率：（本年度總件數－前一年度總件數）÷ 前一年度總件數 × 100%。
- 這份資料反映消費諮詢件數，不等同於消費交易總量、實際損失金額或全台消費者狀況。
- 年度變化可能受通報習慣、案件分類與行政作業等因素影響，不能單憑件數推論商品品質或消費風險變化。
